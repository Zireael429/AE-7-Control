An unofficial utility for the Creative Sound Blaster AE-7 for Windows. Output switching and basic audio settings are combined in a single window.

## What it can do

- Switches between headphones and speakers, including from the taskbar menu. Adjusts volume and checks the left and right channels.
- Controls Direct Mode and the digital filter. For Direct Mode on speakers, select stereo.
- Allows you to select the headphone model and gain, save the gain, and enable virtualization for the line output. Stereo, 2.1, 5.1, speaker type, full-range channels, and bass frequency are available for speakers.
- Includes 33 factory SBX profiles, manual effect adjustments, custom profile storage, Scout Mode, and a 10-band equalizer with 44 presets.
- Changes the playback format and microphone recording level for the AE-7.

SBX and the equalizer are available when Direct Mode is disabled. The digital filter is available in Direct Mode if supported by the driver.

## Installation

Requires a Sound Blaster AE-7, Windows 10 or 11, and .NET Framework 4.8 or 4.8.1.

1. Install the Creative driver for the AE-7. Downloads are available on the official Sound Blaster AE-7 support page.
(https://support.creative.com/Products/ProductDetails.aspx?prodID=23374).
2. If .NET Framework 4.8 or 4.8.1 is not already installed, download the runtime from the Microsoft website.
(https://dotnet.microsoft.com/en-us/download/dotnet-framework).
3. Download `AE7-Control-1.2.2-Setup.exe` from the Releases section, run the installer, and open AE-7 Control from the Start menu.

You can close Sound Blaster Command to use this. The `sbz-switch.exe` wizard is installed along with AE-7 Control.

## Resources Used

- [sbz-switch 4.1.0](https://github.com/mdonoughe/sbz-switch/releases/tag/v4.1.0) by Matthew Donoughe controls the card's parameters. The MIT license is included in `LICENSE-sbz-switch.txt`. - The factory profile skins (`Assets/Profiles/`), SBX and EQ values ​​(`CreativePresets.json`), and headphone model names (`HeadphoneModels.tsv`) were taken from Sound Blaster Command for the AE-7. The skins and presets are integrated into the application.
- The interface icons and background are rendered in WPF. The application icon is stored in `AE7.ico` and `AE7-window.png`. The test signal is generated by the program.

Reading of headphone models was tested on a physical AE-7. The settings application scenarios were tested using a simulated driver.
